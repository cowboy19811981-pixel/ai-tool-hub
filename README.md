# AI Compass | 次世代AI総合ポータル＆自律レコメンドプラットフォーム

AI初心者から実務家、クリエイター、エンジニアまで幅広い層が利用できる最新AI情報・比較・診断Webポータル。
主要6分野×各10種（計60サービス）のデータベースを保持し、12時間ごとの自動ニュース収集・要約、動的ランキング更新、2系統のパーソナライズ診断、および実践プロンプト図鑑を提供します。

---

## 🌟 主な機能と特徴

1. **6分野 × 各10種 ＝ 計60ツール完全網羅カタログ**
   - 総合（LLM）、文書・リサーチ、画像生成、映像・動画、音楽・音声、コード・開発
   - 最新バージョン特性（前世代からの進化点・得意・苦手）
   - 無料版の制限 vs 有料版で解放される決定的なメリット（課金推奨度：★1〜★5）
   - 世界の推計ユーザー規模 ＆ サイト内愛用登録者数ランキング
   - 複合フィルター（無料枠あり、日本語対応、商用利用OK、API提供、アプリ有無）
2. **最大3ツールの横並びスペック徹底比較**
   - 任意のツールを選択し、画面下部のフローティングドックから一発で左右比較表を展開。
3. **2系統のパーソナライズ診断エンジン**
   - **診断A（やりたいこと自由入力診断）**: 自然言語で要望を入力すると、Gemini APIが最適な上位2〜3ツール、推奨理由、コピペ推奨プロンプトを回答。
   - **診断B（4問適性診断）**: 目的・予算・スキル・デバイスの4問クイズで最適ツールを判定＆X（Twitter）シェア機能。
4. **12時間ごとの自動更新 ＆ 動的ランキング**
   - 公式リリースノートやニュースを取得し、Geminiで「初心者向け3行要約」を生成。
   - アップデートされたツールに注目スコアが加算され、ランキング順位が自動で入れ替わる動的アルゴリズム。
   - GitHub Actions（`.github/workflows/cron-update.yml`）により、**PCの電源を切っていてもクラウド上で完全自動運用**。
5. **実践コンテンツ**
   - ワンクリックコピー対応のプロンプト図鑑
   - 同一指示での生成結果の違いを視覚的に比べる出力比較ギャラリー
   - ブラウザに愛用AIをストックできる「My AI Stack」

## 🚀 ローカル起動手順

### 1. 依存関係のインストール & データベース初期化
\`\`\`bash
# 依存ライブラリのインストール
npm install

# データベースのセットアップ & 60ツールシード投入
npx prisma db push
npm run db:seed
\`\`\`

### 2. 開発サーバーの起動
\`\`\`bash
npm run dev
\`\`\`
ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

---

## 🔑 環境変数設定（`.env`）

\`\`\`env
# データベース接続 (ローカルSQLite)
DATABASE_URL="file:./dev.db"

# Google Gemini APIキー (https://aistudio.google.com/ で無料取得可能)
GEMINI_API_KEY=""

# 使用モデル (gemini-2.0-flash / gemini-1.5-pro 等)
GEMINI_MODEL="gemini-2.0-flash"
\`\`\`
※APIキーが未設定の場合でも、内蔵のインテリジェント・フォールバックにより全機能が100%安全に動作します。

## ⏰ 12時間ごとの自動更新バッチの手動テスト

\`\`\`bash
# コマンドラインから実行
npm run cron:update

# またはWebブラウザ/APIから即時実行
